# 社区特殊人员关怀码 · 使用说明

## 这是什么

一套"防走失 / 防意外"关怀码：把信息做成手机友好页面，配一个二维码。
路人扫码 → 立即看到救助所需信息（体貌特征 + 社区紧急电话 + 110/120）。
病史、住址、家人电话等隐私信息**不直接公开**，需家属输入验证码解锁。

## 文件清单

| 文件 | 作用 |
|---|---|
| `index.html` | 信息展示页（手机优先，可打印） |
| `care-qr-demo.png` | 演示二维码（当前指向临时演示链接，约一周后过期） |
| `gen_qr.py` | 一键重新生成二维码的脚本 |
| `README.md` | 本说明 |

## 使用三步

### 第 1 步：改信息
用记事本打开 `index.html`，只改文件开头的 `DATA` 配置区：

- 人员姓名（公开版建议只写称呼，如"王奶奶"）
- 社区紧急电话 `phone`
- 体貌特征 `feats`（可增删行）
- 家属验证码 `family.code`（**务必修改**，不要用示例 1024）
- 家属完整信息 `family.items`
- 照片：把照片放入 `assets/` 文件夹，在 `photo` 填文件名（如 `assets/wang.jpg`），不放则显示占位

### 第 2 步：部署（让页面有一个长期有效的网址）
任选其一：

1. **社区公众号文章**（推荐，最简单）：把页面内容整理成公众号图文，记下文章链接
2. **GitHub Pages**（免费永久）：注册 GitHub → 新建仓库 → 上传 `index.html` → Settings 开启 Pages，得到 `https://用户名.github.io/仓库名/`
3. **云存储静态托管**：阿里云 OSS / 腾讯云 COS 开通"静态网站托管"，上传 `index.html`，得到访问地址
4. **飞书文档**：新建文档粘贴页面内容，分享设置为"组织外可阅读"，复制分享链接

### 第 3 步：生成正式二维码
部署后把网址传给脚本，一条命令生成正式码：

```bash
pip install qrcode pillow
python3 gen_qr.py "https://你的页面地址/" care-qr.png
```

打印 `care-qr.png`（建议 5cm×5cm 以上），塑封后做成胸牌 / 挂绳卡 / 贴纸，
佩戴在特殊人员胸前或常穿衣物上。也可以用硬卡打印，挂在家门口备用。

## 重要提醒

1. **二维码必须指向长期有效的网址**，否则贴出去几个月后扫码会失效。部署后务必先用手机扫码实测一次。
2. **隐私保护**：公开版不显示全名、住址、病史；完整信息靠验证码保护。验证码请设置成家属易记、外人难猜的（如 6 位数字），并定期更换。
3. **信息更新**：电话、住址、病史变化时，改 `index.html` 重新部署，并重新生成二维码（同一网址则旧码仍有效，无需回收）。
4. **法律合规**：采集使用个人信息前，建议征得本人及家属同意，并在社区备案；信息仅用于救助。
5. 演示二维码 `care-qr-demo.png` 指向临时演示链接，约 7 天后过期，仅用于体验流程，不可正式使用。
