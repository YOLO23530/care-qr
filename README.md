# 社区特殊人员关怀码 · 使用说明

## 这是什么

一套"防走失 / 防意外"关怀码：把信息做成手机友好页面，配一个二维码。
路人扫码 → 立即看到救助所需信息（体貌特征 + 社区紧急电话 + 110/120）。
病史、住址、家人电话等隐私信息**不直接公开**，需家属输入验证码解锁。

已部署到 GitHub Pages（免费永久）：https://yolo23530.github.io/care-qr/

## 一人一码

每位特殊人员拥有**独立信息页 + 专属二维码**，扫码只看到本人信息，互不干扰。

| 文件 | 作用 |
|---|---|
| `members.json` | **人员名单（唯一要维护的文件）**，一人一条记录 |
| `template.html` | 页面模板（一般不用改） |
| `build.py` | 批量生成脚本：自动产出每人页面 + 每人二维码 + 管理总览页 |
| `people/<id>.html` | 每人生成的独立信息页 |
| `qr/<id>.png` | 每人生成的专属二维码 |
| `index.html` | 管理总览页（含全部二维码，不含隐私，仅内部用） |
| `gen_qr.py` | 单个二维码生成工具（build.py 内部调用） |

### 日常维护（三步）

1. **改名单**：编辑 `members.json`，新增/修改人员记录。每条记录含：
   - `id`：唯一标识（英文，如 `wang`），二维码地址由它决定
   - `no`：编号（如 `001`），显示在卡片上
   - 公开信息：`name`（建议只写称呼）、`gender`、`age`、`addr`、`phone`（社区紧急电话）、`feats`（体貌特征，可增删）
   - 家属信息：`family.code`（**每人一个验证码，务必修改**）、`family.items`（病史/用药/住址/家人电话）
   - 照片：可选，把照片放到 `assets/` 后填 `photo: "assets/xxx.jpg"`
2. **重新生成**：在项目文件夹运行 `python3 build.py`
3. **上线**：`git add -A && git commit -m "更新" && git push`

> 只要不修改人员的 `id`，二维码地址就不变，**已打印贴出的二维码无需更换**。

## 二维码地址规律

- 王奶奶：`https://yolo23530.github.io/care-qr/people/wang.html` → 二维码 `qr/wang.png`
- 新增人员：`id` 为 `zhao` → 地址为 `.../people/zhao.html`，二维码 `qr/zhao.png`

打印二维码（建议 5cm×5cm 以上），塑封后做成胸牌 / 挂绳卡 / 贴纸，
佩戴在特殊人员胸前或常穿衣物上。

## 重要提醒

1. **隐私保护级别（务必理解）**：本方案部署在 GitHub Pages，属于静态网页，**页面源码对所有人公开**——懂技术的人查看网页源代码就能看到家属验证码和完整信息。因此"家属专区"的验证码只能做到**防路人误看、防随手转发**，不是真正的加密保护。**身份证号、银行卡等最高敏感信息请勿放入**；病史、住址等建议先征得家属同意。一人一码的好处是：每个页面只暴露一个人的信息，泄露面最小。
2. **验证码**：每人设置成家属易记、外人难猜的（如 6 位数字），定期更换。若需要更强的隐私保护（验证码服务端校验），需改用带后端的方案，本静态方案不适用。
3. **法律合规**：采集使用个人信息前，建议征得本人及家属同意，并在社区备案；信息仅用于救助。
4. 管理总览页 `index.html` 不含隐私信息，但也请勿对外转发。
