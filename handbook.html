A新增一位人员

全程约 3 分钟，只需要复制粘贴改几个字

1
打开 https://github.com/YOLO23530/care-qr，点击文件列表里的 members.json。
2
点击右上角 铅笔图标（Edit this file），进入编辑界面。
3
滚动到文件末尾。关键：新记录要粘贴在最后一条记录 } 的下面、数组结束符 ] 的上面。先看粘贴前文件末尾长这样：
粘贴前（注意最后两行是 } 和 ]）： } ] 在 } 后面加一个逗号 ,，然后换行粘贴下面模板，最终应变成（新记录必须在 ] 的上面）： }, { "id": "zhao", "no": "003", ...（模板内容，见下）... } ] 千万不要把内容粘贴到 ] 的下面或文件最末尾——那样系统会解析失败，二维码不会生成。
下面是空白模板（整段复制，粘贴后逐项修改）： { "id": "zhao", "no": "003", "org": "朝阳社区居民委员会", "subLine": "如您遇到需要帮助的人，请扫码查看救助指引", "name": "赵爷爷", "gender": "男", "age": "75", "addr": "朝阳社区", "tag": "重点关注对象", "phone": "0431-88888888", "photo": "", "feats": [ ["身高", "约165厘米"], ["体型", "中等"], ["发色", "花白短发"], ["衣着", "常穿蓝色外套"], ["特征", "说话声音洪亮"], ["习惯", "喜欢在小区门口晒太阳"] ], "family": { "code": "520003", "items": [ ["紧急联系人", "赵女士（女儿） 138-0000-0003"], ["家庭住址", "朝阳社区 6 栋 2 单元 101"], ["病史", "无重大病史"], ["用药", "无长期用药"], ["饮食注意", "无特殊忌口"], ["注意事项", "喜欢独自散步，注意天色"] ], "warn": "温馨提示：老人如有突发不适，请立即拨打 120，并告知医护人员上述病史与用药情况。" } }
4
把模板里的内容改成这位人员的真实信息：id（英文，如 zhao，以后别改）、no（编号）、name（称呼）、family.code（家属验证码）等。字段含义见 第 F 节。
5
点绿色按钮 Commit changes… → 在弹窗里点 Commit changes 确认。系统自动开始生成，等 1～2 分钟。
6
回到仓库首页，点击 qr 文件夹 → 找到新人员的图片（如 zhao.png）→ 点开 → 点 Download 下载，打印即可使用（见 第 D 节）。
完成！新人员的专属页面也会自动生成，网址是 https://yolo23530.github.io/care-qr/people/zhao.html，扫码就能验证。

B修改人员信息

电话换了、病情变了、验证码想改——都这么做

1
打开 members.json，点右上角铅笔图标编辑。
2
找到对应人员，直接改里面的内容（比如把 "phone": "0431-88888888" 改成新号码）。
3
点 Commit changes… → Commit changes，等 1～2 分钟自动更新。
修改信息不会改变二维码——只要不改 id，已打印贴出的二维码依然有效，不用重新打印。改完可以用手机扫一下码确认新内容已生效。

C删除人员

1
编辑 members.json，把该人员的整段记录（从 { 到 }）删掉，注意删掉后前面一条记录结尾的逗号 , 也要去掉，保持格式正确。
2
点 Commit changes… → Commit changes。
3
系统会自动删除该人员的页面和二维码文件。已打印的二维码请及时回收，避免误用。

D下载 / 打印二维码

1
仓库首页点击 qr 文件夹，里面每位人员一个图片文件（如 wang.png、li.png）。
2
点开图片 → 点 Download 下载原图（在电脑上点 Download raw file 也可以）。
3
用图片软件或文档打印，边长建议不小于 5 厘米（约两张银行卡宽），黑白打印即可识别。
4
打印后塑封或贴透明胶防水，做成胸牌、挂绳卡，佩戴在人员胸前或常穿衣物口袋上。
打印前先用手机扫码测试一次，确认能打开正确的人员页面。

E添加照片（可选）

照片能让路人更快确认身份。步骤：

1
仓库首页点 Add file → Upload files，把你准备好的照片拖进去，注意把上方路径改成 assets 文件夹（点 / 旁的 assets 进入后上传）。
2
在 members.json 对应人员记录里，把 "photo": "" 改成 "photo": "assets/照片文件名.jpg"。
3
提交（Commit changes），等自动生成后扫码验证。
照片会公开显示，请确认本人及家属同意后再上传。建议用生活近照，正面、光线充足。

F字段填写说明

字段填什么注意
id英文标识，如 wang、zhao每位人员唯一，定下后不要改——它决定二维码地址
no编号，如 001、002显示在卡片上，方便管理
org主办单位名称一般所有人员相同
name称呼，如"王奶奶"公开显示，建议只写称呼不写真名全名
gender/age/addr性别 / 年龄 / 社区公开显示
phone社区 24 小时紧急电话路人扫码一键拨打，务必准确
feats体貌特征，每行 ["项目","内容"]身高、衣着、特征、习惯等，越具体越易辨认
family.code家属验证码（数字）每人不相同，务必修改默认值，家属易记、外人难猜
family.items家属信息：联系人、住址、病史、用药等验证码解锁后可见，扫描页面的人看不到
warn紧急提示语一般不用改
photo照片路径，如 assets/xx.jpg不放照片就留 ""
隐私提醒：本系统是公开网页，验证码和家属信息在技术上"防君子不防小人"（懂技术的人查看网页源代码能看到）。请勿填写身份证号、银行卡号等最高敏感信息；病史、住址等建议先征得本人及家属同意。

G常见问题

改完没反应 / 页面没更新？

确认点了 Commit changes 并成功提交；系统自动生成需要 1～2 分钟，稍等后刷新；仍不行就在仓库首页点 Actions 标签看有没有红色失败的记录。

误删了记录 / 改坏了格式？

编辑界面点 Commit changes… 旁边有 …，可以回退；或联系管理员用"历史版本"恢复（仓库 → 点文件 → History）。

验证码忘了怎么办？

打开 members.json 编辑，直接改 family.code 为新验证码，提交后自动生效。

我想给老人换一张新二维码？

不需要换——同一人信息更新后，旧码继续有效。只有改了 id 才需要重新打印。

社区电话需要分时值班怎么办？

可以准备两个电话：页面显示社区总机；110 / 120 按钮始终可用，路人扫码后总有一条路能联系上。
